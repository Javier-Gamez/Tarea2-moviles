# Catálogo de Elementos de Interfaz de Usuario

Aplicación que funciona como un catálogo interactivo de componentes de interfaz móvil, implementada en tres tecnologías distintas para comparar sus equivalencias y enfoques de construcción.

> Documento en construcción.

## Estructura del repositorio

```
android-views/     Versión con Views y XML
android-compose/   Versión con Jetpack Compose
flutter/           Versión con Flutter
docs/              Capturas de pantalla
apks/              APK de cada versión
README.md          Documento principal
```
